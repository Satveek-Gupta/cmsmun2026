Official website for **CMS Model United Nations 2026** (5th Edition) Organised by City Montessori School, Aliganj Campus I, Lucknow.

## About

CMSMUN '26 is a Model United Nations conference platform for young leaders to engage in realistic diplomacy, meaningful activism, and global perspectives. The conference will be held on **24th and 25th April, 2026** in Lucknow, India.

This website provides information about the conference, committees, executive board, secretariat, registration, and background guides.

## Purpose

This website serves as the official platform for CMSMUN 2026, providing delegates and participants with:
- Conference information and details
- Committee listings and agendas
- Registration portal
- Executive board and secretariat information
- Background guides and resources
